## Факты (проверено 05.10.2026)
- Таиланд — полноправный участник APEC Business Travel Card. Держателям карты с кодом THA на обороте — въезд без визы для деловых поездок до 90 дней.
- С 15.09.2026 обычный безвиз — 30 дней и только туризм; программу APEC изменения не затронули.
- Карта — не разрешение на работу: работа по найму в Таиланде только с work permit. Решение на границе за офицером.
- Включение в пул внешнеторговых советников ВЭД-компании — формальный статус для подачи, обязательств не несёт (база знаний CRM).
