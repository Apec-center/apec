## Откуда цифры
Книга продаж, раздел 6 «Что даёт карта: с картой и без» (ИН-09, ИН-10), данные сверены 27.09.2026:
- Вместо визы: Сингапур (60), Тайвань (90); Япония, Австралия, Новая Зеландия — только при одобрении, не обещаем.
- Дольше за въезд: Таиланд 30→90, Бруней 14→90, Гонконг 14→60, Бали ~30→60, Китай и Малайзия 30→60, Филиппины 30→59, Вьетнам 45→60.
- Меньше формальностей: Корея 90 без K-ETA (без карты 60 + K-ETA), Мексика 90 по карте, коридор APEC, одна проверка на 5 лет.
- Расширение до 90 дней в Китае, Гонконге, Индонезии, Филиппинах и Сингапуре — «объявлено, дата не назначена».
Тема «APEC против DTV» из плана пропущена: книга продаж запрещает называть условия и цены чужих виз.
