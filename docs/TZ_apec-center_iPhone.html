1Итог

На iPhone страница apec.center показывает только статичную вёрстку: нет цен, анимаций, таймера, карты стран, не работают переключатель валют и кнопка «Сравнить с самостоятельным путём». Всё это одна ошибка. Скрипт страницы падает на рисовании карты и дальше не выполняется. Исправление проверено на эталонной сборке. Осталось перенести его на боевой сайт.

3Причина

На ширине до 980px блок карты .map-box задан через aspect-ratio:16/10 внутри строки сетки с растяжением по высоте. Safari на iOS считает его высоту равной нулю. Функция fit() из нулевой высоты получает отрицательный масштаб, и ctx.arc() вызывается с отрицательным радиусом. Браузер бросает исключение:

IndexSizeError: Failed to execute 'arc' on 'CanvasRenderingContext2D':
The radius provided (-0.0988235) is negative.

Весь JavaScript страницы выполняется одной функцией, поэтому исключение останавливает всё, что объявлено после карты: цены, валюты, тарифы, таймер, трекер, квиз и анимации появления.

Исправление в три слоя: блоку карты задаётся реальная высота, масштаб не может стать отрицательным, а любой сбой рисования карты перехватывается и больше не роняет страницу.

5Порядок внедрения

  1. Сохранить копию текущего index.html с сервера.
  2. Внести 8 замен из раздела 4. После каждой убедиться, что поиск по старому фрагменту больше ничего не находит.
  3. Проверить, что в файле есть ровно одно объявление function safe(.
  4. Открыть страницу в десктопном браузере: консоль без ошибок, карта и цены на месте.
  5. Загрузить файл на хостинг и сбросить кэш CDN, если он есть.
  6. Пройти чек-лист из раздела 6 на настоящем iPhone.

Откат: вернуть сохранённую копию. Правки не меняют тексты, ссылки, цены и счётчики аналитики.
