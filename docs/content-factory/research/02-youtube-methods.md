## Краткий вывод: что взять в APEC-контент-завод

1. **Начинать не со сценария, а с «аудитория → продукт → задача контента».** Анарбаева прямо формулирует: работа над роликом начинается с анализа аудитории, продукта и задачи контента. [сниппет первоисточника, smmconfa.ru]
2. **Редакционная матрица отвечает на вопрос: «что человеку нужно понять/увидеть/услышать, чтобы сделать следующий шаг покупки».** Это смысловой, а не тематический документ. [сниппет первоисточника, sozai.app]
3. **У каждой единицы контента — одна цель** (охват, вход в воронку, прогрев, продажа), которую потом меряют в аналитике. [сниппет первоисточника + пересказ]
4. **Матрица раскладывается по ступеням осознанности (Хант) и по «лестнице внимания/триггеров»** — разные ступени требуют разных смыслов и разного тона. [сниппет первоисточника]
5. **Хук закладывается на этапе матрицы, а не монтажа** («хук — 50% успеха»). [сниппет первоисточника, sozai.app]
6. **Анатомия сильного ролика по Анарбаевой: угол подачи → хук → драматургия → доказательства → экспертный вывод → переход к продукту.** Это готовый шаблон полей карточки сценария. [сниппет первоисточника, smmconfa.ru]
7. **Короткие видео привлекают новых, длинные строят доверие** — их надо связывать в одну систему, а не делать параллельно. [сниппет первоисточника]
8. **«Суть одна — форматов много»**: одна идея из банка → пост, сторис, ролик, реклама, статья. Совпадает с reverse pyramid Gary Vee и моделью Dan Koe. [пересказ + сниппеты]
9. **Банк идей/смыслов — постоянно пополняемый актив**, а рубрикатор описывает назначение каждой рубрики. [сниппет первоисточника]
10. **Сценарий Reels = хук 1–3 с + мини-хуки каждые 3–10 с + выполнение обещания + триггер сохранения/CTA** (рынок Reels, в т.ч. курс Исмаилова). [пересказ]
11. **Хук бывает трёх каналов: слово, текст на экране, картинка** — генерировать все три для каждого ролика. [пересказ]
12. **«100 Reels по одной кнопке» не продают**: нейросеть масштабирует, но методику, проверку гипотез и ручную работу креатора она не заменяет. [пересказ, sostav.ru]
13. **Дистрибуция равна по весу созданию** (Ross Simmonds: Research → Creation → Distribution → Optimization; «создай один раз — распространяй всегда»). [пересказ]
14. **Templatize лучшего** (Justin Welsh): собирать сработавшие форматы в шаблоны и перезапускать удачные идеи с новым углом. [пересказ]
15. **Кабинет креатора/амбассадора = бриф → черновик → статусы Pending / Approved / Revision / Rejected → Published** с комментариями и дедлайном правок. [пересказ, документация платформ]

### 1.2. Базовые принципы [сниппет первоисточника, если не указано иное]

1. **Контент как система, а не набор случайных публикаций.** Повторяется во всех описаниях видео про матрицу.
2. **Редакционная матрица = маркетинг + журналистика → бренд-медиа.** Её задача — уйти от «часов на бесполезный контент» к предсказуемому графику публикаций, ведущему к целям. (sozai.app, content-strategy-attracts-clients)
3. **Главный вопрос матрицы:** «что человеку нужно понять — какой смысл — увидеть, прочитать, услышать, чтобы он сделал следующий шаг покупки». (sozai.app; https://sozai.app/transcript/content-strategy-attracts-clients/)
4. **Хуки закладываются при разработке матрицы**, «хук — 50% успеха». (там же)
5. **Контент сам по себе не гарантирует продаж** — нужна выстроенная контент-воронка: контакт с контентом → лид-магнит → канал коммуникации → покупка. Лид-магнит — инструмент сбора контактов и подготовки к покупке, а не финальный продукт. (там же)
6. **Матрица распределяет контент по уровням осознанности**: сформировать представление о решении проблемы → объяснить, какую проблему решаем → показать, почему продукт лучший → объяснить конкурентные преимущества. (сводка поиска по видео Анарбаевой)
7. **«Лестница внимания»** — инструмент создания контента для разных стадий осознания проблемы, в т.ч. для работы с горячим и сформированным спросом. (sozai.app, content-theme-builder) Это её адаптация лестницы Ханта; точная формулировка ступеней в доступных сниппетах не раскрыта.

### 1.3. Анатомия ролика (технология коротких и длинных видео для сложных экспертных ниш)

По описанию мастер-класса на «Суровом Питерском Форуме» 2026 (https://smmconfa.ru/spik2026/anarbaeva_nata/) [сниппет первоисточника]:

- Элементы сильного ролика: **угол подачи, хук, драматургия, доказательства, экспертный вывод, переход к продукту**.
- Работа начинается **не со сценария**, а с анализа аудитории, продукта и задачи контента.
- Как **упаковать сложную экспертизу, не скатываясь в банальности**; превращать сложные мысли в понятные сюжеты.
- Как находить темы, которые цепляют широкую аудиторию.
- **Короткие видео привлекают новую аудиторию, длинные — строят доверие**; каждый формат решает свою задачу и связывает просмотры с ростом аудитории, заявками и продажами.

### 1.5. Реконструкция цепочки Анарбаевой [вывод]

Из пунктов выше складывается порядок, который совпадает с формулой «сначала смыслы, потом темы»:

```
Продукт + аудитория + задача контента
  → Банк смыслов (что человек должен понять на каждом шаге покупки)
  → Ступени осознанности / лестница внимания (какой смысл для какой ступени)
  → Рубрикатор (рубрика = назначение + цель + ступень)
  → Редакционная матрица (одна таблица: смысл × ступень × рубрика × формат × цель × хук)
  → Темы (конкретные заголовки/углы из пересечений)
  → Сценарий (угол → хук → драматургия → доказательство → вывод → переход к продукту)
  → Адаптация под площадки (короткое привлекает, длинное греет)
  → Аналитика по цели единицы контента
```

**Вероятные столбцы матрицы** [вывод; из сниппетов подтверждены «смысл», «следующий шаг покупки», «уровень осознанности», «хук», «цель единицы контента», «рубрика», «формат», «площадка»]:

| Сегмент | Ступень (Хант/внимание) | Смысл (что понять) | Следующий шаг | Рубрика | Тема/угол | Хук | Формат | Площадка | Цель единицы | Метрика |
|---|---|---|---|---|---|---|---|---|---|---|

### 2.3. Лестница узнавания Бена Ханта в контенте

- 5 ступеней: нет проблемы/безразличие → осознание проблемы → сравнение способов решения → выбор поставщика → готовность купить. [пересказ: https://kokoc.com/blog/lestnica-bena-hanta/ , https://www.bitrix24.ru/journal/lestnica-bena-hanta , https://getcourse.ru/magazine/chto-takoe-lestnica-hanta]

[пересказ: https://tenchat.ru/media/5354658-ben-khant-yego-lestnitsa-ii]
- Сравнение подходов: https://www.sostav.ru/blogs/269762/41442 («о чём писать, чтобы прогревать всех — от холодных до горячих»).

### 2.4. Англоязычные модели

- **Gary Vaynerchuk — Reverse Pyramid**: один «pillar content» (влог, кейноут, Q&A-шоу) → команда выбирает фрагменты → десятки микро-единиц под контекст каждой платформы (короткие видео, статьи, картинки) → follow-up статьи в Medium/LinkedIn/сайт/email. «Одно видео → 30 единиц». [пересказ: https://biteable.com/blog/gary-vees-content-framework-one-video-30-content-pieces/ ; первоисточник: https://garyvaynerchuk.com/the-garyvee-content-strategy-how-to-grow-and-distribute-your-brands-social-media-content/ — не открыт]
- **Justin Welsh — Content OS**: Curate (собирать высокоэффективный контент) → Templatize (превращать в шаблоны, база) → Create (10–15 идей в день по шаблонам) → Distribute (автоматизация). Библиотека лучших постов перезапускается с обновлениями — «730-дневный календарь». [пересказ: https://thevicmontano.substack.com/p/content-os-by-justin-welsh-an-automated , https://thewayup.beehiiv.com/p/how-justin-welsh-built-1-5m-followers-with-a-content-system]

## 3. Как сложить это в одну систему для APEC Center [вывод]

**Слой 1. Стратегия.** Сегменты (зимовщики, предприниматели, семьи, уже на Пхукете, только планируют) × продукт (карта APEC, 90 дней) × цель на квартал. Редполитика в стиле бренд-медиа: тон, запреты (никаких обещаний, которые зависят от миграционной службы), факт-чек.

**Слой 2. Банк смыслов (Анарбаева).** Для каждого сегмента: что человек должен понять, чтобы сделать следующий шаг (например, «визаран — это риск и деньги» → «есть легальный способ на 90 дней» → «APEC Center делает это под ключ»). Пополняется из вопросов в чатах, комментариев и CRM.

**Слой 3. Матрица = смысл × ступень Ханта × рубрика × цель.** Одна таблица (n8n Data Table / Notion). Хук и угол рождаются уже здесь.

**Слой 4. Темы и углы.** Каждая строка матрицы порождает 3–10 углов (история, цифра, миф, сравнение, ошибка, кейс). Claude генерирует, человек утверждает.

**Слой 5. Pillar → spokes (Gary Vee / Dan Koe / Simmonds).** Еженедельный pillar: длинное видео спикера или SEO-статья. Из него: 2 спикера × Reels, карусели, Telegram-посты, Дзен/vc.ru-адаптации, креативы для рекламы и рефералов. 30+ единиц в неделю = примерно 3 pillar × 10 spokes.

**Слой 6. Сценарий (шаблон полей).** Угол → хук (слово/текст/картинка) → мини-хуки → драматургия → доказательство (кейс, документ, цифра) → экспертный вывод → переход к продукту/CTA → цель единицы.

**Слой 7. Производство.** Статусы карточки: Идея → Утверждена → Сценарий → Съёмка/Генерация (kie.ai: Veo/Kling для Б-роллов) → Монтаж → QA-гейт (факт-чек, юр.проверка) → Запланировано → Опубликовано → Проанализировано. Медиатека Б-роллов с тегами (локация, сезон, сюжет), чтобы ИИ-генерация закрывала только пробелы.

**Слой 8. Амбассадоры/креаторы.** Кабинет: бриф из строки матрицы → черновик → Pending/Approved/Revision/Rejected → Published + реф-ссылка для атрибуции.

**Слой 9. Метрики по цели единицы.** Охват/досмотр для ступени 1–2, сохранения/переходы для 3–4, заявки и реф-продажи для 5. Цикл Welsh: лучшее → шаблон → перезапуск с новым углом через 1–3 месяца.
